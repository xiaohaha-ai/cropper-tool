# 裁切台

一个纯前端图片裁切工具。图片仅在浏览器的 Canvas 中读取、识别和导出，不会上传到服务器。

## 浏览器使用

GitHub Pages 会在推送 `main` 分支后自动发布。首次部署时，在仓库的 **Settings -> Pages** 中将 Source 设为 **GitHub Actions**。

网站首次在线打开后会缓存应用程序文件；之后可以安装为桌面或手机应用，并在离线状态下继续使用。浏览器本地处理的图片不会进入缓存或上传。

本地预览请使用静态服务器，例如：

```sh
python3 -m http.server 4174
```

然后打开 `http://127.0.0.1:4174/`。直接打开 `index.html` 可以裁切图片，但浏览器安全限制会禁用离线缓存和安装功能。

## 功能

- JPG、PNG、WebP 上传或拖拽导入
- 原图、1:1、4:5、3:2、16:9、自由裁切
- 图片拖拽定位、缩放、旋转和水平/垂直翻转
- 九宫格分割与选择性批量导出
- 智能识别清晰的卡片、按钮、分隔拼图及基础异形图框
- 候选图框的选择、移动、缩放和四边拉伸
- 异形图框透明 PNG、PNG/JPG 单图和 ZIP 批量导出
- 滚轮缩放画布，空格加左键或中键平移画布
