# 裁切台

一个包含裁切、去水印和免费字体库的纯前端工具站。图片仅在浏览器的 Canvas 中读取、识别和导出，不会上传到服务器。

## 浏览器使用

GitHub Pages 会在推送 `main` 分支后自动发布。首次部署时，在仓库的 **Settings -> Pages** 中将 Source 设为 **GitHub Actions**。

网站首次在线打开后会缓存应用程序文件；之后可以安装为桌面或手机应用，并在离线状态下继续使用。浏览器本地处理的图片不会进入缓存或上传。

本地预览请使用静态服务器，例如：

```sh
python3 -m http.server 4174
```

然后打开 `http://127.0.0.1:4174/`。直接打开 `index.html` 可以裁切图片，但浏览器安全限制会禁用离线缓存和安装功能。

## 功能

- JPG、PNG、WebP 上传或拖拽导入
- 原图、1:1、4:5、3:2、16:9、自由裁切
- 图片拖拽定位、缩放、旋转和水平/垂直翻转
- 九宫格分割与选择性批量导出
- 智能识别清晰的卡片、按钮、分隔拼图及基础异形图框
- 候选图框的选择、移动、缩放和四边拉伸
- 异形图框透明 PNG、PNG/JPG 单图和 ZIP 批量导出
- 手机端自动导出 JPG，并优先通过系统分享面板将单图或多图存入相册，不支持时回退到下载目录
- 滚轮缩放画布，空格加左键或中键平移画布

## 免费字体库

导航中“去水印”右侧的“免费字体库”进入 `fonts.html`。收录 51 款字体、136 种样式，支持中英文预览、字体搜索与收藏、字重和可变轴、排版调整及带格式文字复制。

字体以 WOFF2 格式按需下载，进入裁切或去水印页不会预加载字库。复制的富文本使用字体内部名称；目标软件需安装对应字体并支持保留源格式。英文专用字体的中文会由系统字体补齐，页面会提示。

字体文件位于 `font-library/fonts/`，原始许可和说明位于 `font-library/licenses/`。字体遵循各自授权，不适用本项目代码的 MIT 许可。
