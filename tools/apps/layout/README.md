# 秀米风格图文排版编辑器

基于用户提供的秀米图文编辑器截图制作的独立本地 Web 应用。界面沿用深灰素材栏、白色文章画布、双层悬浮工具条和右侧快捷操作，不依赖秀米登录。

这不是秀米官方产品，也不等于秀米全量功能复刻。当前交付的是可编辑、可保存、可导出的本地版本。服务端能力和未能核对的官方隐藏功能见下表。

## 启动

需要 Node.js 22.18+（本次使用 Node.js 24）。

```bash
npm install
npm run dev
```

访问终端显示的本地地址。本项目固定使用 `http://127.0.0.1:5174`。也可以双击 `启动编辑器.command`。

```bash
npm run build    # TypeScript 校验和生产构建，输出 dist/
npm run preview  # 预览生产构建，默认端口 4173
npm test         # 工程导入、链接和 HTML 清洗测试
```

## 图库分组与删除

“我的图库”和“图片素材”共用本机素材库。可以新建、重命名分组，在缩略图下移动单个素材，或用“批量管理”全选当前分组后移动、删除。分组内上传的图片会自动归入当前分组；旧素材显示在“未分组”。

图片可从电脑直接拖入图库，自动归入当前分组；拖到文章画布会上传并按文件顺序插入到落点组件后，空白处拖入则追加到文末。支持一次多张 JPG、PNG、GIF、WebP，单张最大 20 MB；整批校验通过后再添加。画布中单击图片只选中，双击才打开替换、尺寸、裁切、圆角、链接等设置；锁定组件与装饰图不会打开图片设置。选中框仅用于编辑，不写入正文或导出文件。

双击图片后，可用“放大 / 缩小”、宽度滑杆或“铺满宽度”按原比例调整大小，再选择左对齐、居中或右对齐，点击“应用图片设置”保存。固定高度且完整显示的图片会从实际可见尺寸开始缩放，避免只扩大空白框；也可继续设置固定高度与裁切方式。图片宽度相对于所在版面或分栏计算，对齐随正文保存并保留在导出结果中。

选中图片后，直接拖动组件最外层边框：四角方形手柄用于等比例缩放，四条边用于裁掉留白，拖动时预览、松手即生效，无需切换模式或点击确认。拖动中按 Esc 取消；缩放和裁切均可撤销，保留完整原内容，并随工程保存及导出。

选中组件后，点击右侧“图层”或工具栏“自由组合”，可将文字、图片作为独立图层自由排列和叠加；图片设置中也有“图片左侧加文字”快捷入口。支持拖动位置、右下角缩放、精确坐标、对齐、置顶置底、复制删除、撤销重做、本地上传与图库添加，以及“左文右图”“文字叠加”快捷布局。文字可更改内容、四款内置字体、字号、颜色、粗细与对齐方式，图层可设置背景和透明度。点击“应用组合”保存，双击正文里的组合继续编辑；取消不改原组件，保存后的图层随工程保留，HTML 和图片导出保留排列效果。复杂原组件会作为一个完整图层保留，新增文字和图片可以在它上方叠加。

删除素材只从图库移除，已插入文章的图片、封面和音视频继续保留。“撤销删除”可恢复本次会话最近一次删除的素材；刷新页面后不保留撤销记录。删除分组需在面板内确认，组内素材会移回“未分组”。所有分组和素材改动自动保存在本机。

## 本次顶部功能

- **更多**：按参考截图分组，包含新建、图文历史、文件导入、公众号内容导入、HTML 代码导入、另存、共享工程、收集图片、长图/PDF/视频、贴纸、一键排版及保存样刊。保留查找替换和快捷键入口。
- **导出**：同步公众号、复制粘贴、同步多图文三个入口。点击“继续用复制粘贴”进入整篇复制预览，可选择“有赞页面编辑”或“普通富文本”。准备就绪后自动全选，点击“复制全部内容”，或按 ⌘C / Ctrl+C、右键复制；到目标文档粘贴并选择“保留源格式”。复制包含全部正文组件（含锁定组件），不包含编辑工具或封面/作者等独立信息字段；退出复制后可继续编辑。未连接公众号时显示真实状态；也可选择最多 8 篇图文下载工程 ZIP。
- **打开**：我的/团队导航、标题和摘要搜索、全文搜索、标签筛选、每页 15 篇、选中后打开、双击打开。团队区域说明当前未连接，可导入别人分享的工程。
- 文件导入提供预览，可以新建图文或追加到文末。DOCX 提取正文、图片与表格；XLSX 导入全部工作表的单元格内容（读取已有公式计算结果）；不承诺保留 Office 的分页、页眉页脚、图表与复杂版式。旧版 DOC/XLS 需先转换。
- 公众号内容通过复制正文后粘贴导入，原文链接可选；未接入凭链接自动抓取。外部图片可能受原站防盗链限制，需要替换或上传。
- 另存与使用样刊都创建独立文稿。共享 JSON 内嵌本地素材，外部图片链接仍依赖网络；不支持直接写入其他人的秀米账号。
- 持久历史按图文保存最近 30 个版本，连续自动保存按自然分钟合并，手动保存及切换/恢复前的版本单独保留。恢复支持撤销；不能找回此功能上线前已经丢失的编辑历史。
- 贴纸图文把正文渲染为 2 倍宽图片，按最高 1600 像素分段，另存为新图文；文字变为图片，原始可编辑稿件保留。
- 视频在浏览器内生成 15 秒、720×1280 的无声滚动视频，支持进度、取消、生成后预览和再次下载。浏览器支持时输出 WebM 或 MP4，不录制麦克风，不播放文章内的音视频。大幅图片/长文受浏览器画布内存限制。
- 一键排版提供简洁阅读、杂志留白、紧凑资讯三种方案，预览后再应用，支持撤销；仅规范正文和标题，锁定组件和装饰卡片保留。

## 使用说明与数据边界

- 所有编辑数据保存在当前浏览器的 IndexedDB，不会自动上传。清除网站数据、使用无痕窗口或换浏览器会影响本机草稿；重要稿件应导出 JSON 备份。
- 导入工程会新建一份图文，不覆盖原图文。切换或新建图文会保留上一份稿件。
- PNG 是文章正文长图，原始图片分辨率决定细节质量。本次继续优化已换成参考页公开展示的 1080px 中秋原图和透明装饰素材，标题文字可直接编辑；来源保存在 `output/reference/asset-sources.json`。
- HTML 导出会移除尺寸容器（`container-type` / `container-name`），并将 `cqw` 等容器单位解析为实际尺寸，避免外部编辑器把图片区域缩成零宽；原稿保留原有响应式样式。
- 顶部“导出 → 导出 HTML 文件”直接下载以文章标题命名的 HTML。内嵌本地图片、正文用到的字体分片及字体许可，保留可选择的真实文字。自行导入的外部 HTTP 图片、音视频仍依赖其服务器；不可用的图片会阻止完整长图导出并提示修正。
- 默认字体为**思源黑体**，字体菜单仅保留用户下载的四款字体：思源黑体 SC 2.005、思源宋体 SC 2.003、阿里巴巴普惠体 3.0、Noto Sans SC 2.004。字体文件随工具本地打包，不依赖系统安装或在线字体服务；包含原生字重，禁止伪加粗。旧稿、粘贴和导入时，其他黑体/未识别字体归为思源黑体，其他宋体归为思源宋体；原有 Noto 黑体映射到下载的 Noto Sans SC。
- 切换字体会先加载对应字重，成功后再更新正文；后台预热常用字重、重复选择复用缓存，连续切换以最后一次为准。选中文字只修改选区，无文字选区时修改整个组件，保留字号、粗细、颜色和排版；加载失败保留原字体并提示重试。HTML/PNG 导出只内嵌文章使用的字体和字重，HTML 附带对应许可或来源说明。
- 字体原始说明位于 `public/fonts/local/*-NOTICE.txt`：思源与 Noto 保留原始 OFL 许可；阿里巴巴普惠体保留下载目录中的官方来源及法律声明链接，未将其误标为 OFL。字体文件不应单独售卖；图片内部已有文字、外部平台复制后对字体的处理不在本地字体限制范围内。
- `scripts/prepare-fonts.py` 可从同级“字体下载”目录重新生成网页字体、`src/fontManifest.json` 与字体 CSS；正常启动无需重新转换。
- 普通富文本复制同时写入 HTML 和纯文字，并内嵌本地图片；此模式不能直接用于有赞。有赞后台的实际反馈显示内嵌图片被丢弃，复杂网格排版也会错位。普通模式已在 Chromium 独立富文本编辑区验证，不能据此推断有赞、Word/WPS 或公众号兼容。
- **有赞兼容复制**：在适合手机的宽度测量排版，将普通 Flex 分栏转换为无边框表格，去除容器尺寸单位；叠放网格、SVG 与变换装饰局部转为高清图片，组合内文字将不能在粘贴后单独编辑，原始文稿保留。准备后提供图片素材 ZIP 和逐图地址输入；将素材上传到有赞素材库，再填入 HTTPS 图片直链。缺地址、地址无效或图片无法加载时阻止复制，验证通过后写入公网地址并保存映射供下次复用。不会自动上传图片到外部图床或有赞，也没有接入有赞上传凭证。
- 若必须完整保留视觉，可点“下载保真长图”并上传到有赞的“图片广告”组件；该方式的所有文字都会变为图片。
- 有赞兼容功能已用实际“全城艺动”工程做本地渲染与浏览器流程验证，包含 6 张导出素材、5 个表格、缺图阻止复制和链接变更失效。公网图片验证环节使用测试替身，没有将测试域名写入真实用户工程。真实有赞上传、粘贴、草稿保存和小程序最终呈现尚待验收。
- 剪贴板权限被拒绝时尝试原生复制，再失败则保留选区供手动复制。纯文本文件不能保留排版，音视频仍取决于目标平台支持。
- PDF 使用浏览器原生打印，不是云端转换；实际分页取决于浏览器和打印设置。
- 撤销历史为当前会话内最多 100 步，不恢复上次会话的撤销栈；已保存版本最多 30 个，可从顶部“更多 → 打开图文的历史记录”跨会话恢复。样刊、图片收集和图文库也保存在 IndexedDB。
- 输入 HTML 通过 DOMPurify 与 URL 规则清洗，禁用脚本、事件、iframe、foreignObject、动态 SVG 等。
- 桌面浏览器是主要使用场景；窄屏自动适配画布，工具条可横向滚动。没有承诺所有移动浏览器的富文本选择和系统剪贴板行为一致。

## 项目结构

- `src/App.tsx`：编辑器工作台、工具条、素材库和弹窗。
- `src/EditableBlock.tsx`：组件编辑、图片交互、拖动入口。
- `src/model.ts`：文章数据模型、内置模板、工程校验与安全清洗。
- `src/useStudio.ts`：本机存储、多文稿、撤销重做与自动保存。
- `src/export.ts`：HTML、PNG、共享工程、贴纸、视频及下载能力。
- `src/CopyExport.tsx`、`src/clipboard.ts`：整篇复制预览、原生选区、富文本剪贴板及权限回退。
- `src/youzanExport.ts`：有赞布局转换、组合图形渲染、图片素材打包与公网地址验证。
- `src/documentTools.ts`：文件解析、搜索、另存、版本记录与一键排版逻辑。
- `src/DocumentPicker.tsx`：搜索、标签与分页的图文选择器。
- `src/WorkflowDialogs.tsx`：顶部操作的预览、确认和连接状态窗口。
- `src/style.css`：参考截图视觉与响应式样式。
- `tests/model.test.mjs`：导入和内容清洗回归测试。
- `tests/export.test.mjs`：导出样式、图片内嵌、读取失败及剪贴板权限回退测试。
- `tests/youzanExport.test.mjs`：有赞图片链接、缺图阻止复制及实际图片加载失败处理。
- `output/playwright/`：本次浏览器验收脚本、截图和导出样本。
