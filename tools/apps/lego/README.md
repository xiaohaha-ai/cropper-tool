# 积木工坊 · 自由拼搭与透明模型拼搭

已准备 **13 类、137 种规格**的 Three.js 参数化零件，并提供分类浏览、搜索、三维检查、8 色切换、连接点显示、单件 GLB 下载和 JSON 目录下载。

现在默认打开拼搭工作台，零件图鉴保留在右上角。支持：

- 从 137 种零件中分类搜索，点击零件后在画布上点击放置；半透明预览，可连续添加。
- 8 mm 凸点网格吸附，普通零件的顶部凸点 / 底部接口叠搭；奇偶规格与绕 Y 轴旋转后的偏移已处理。
- 点击三维零件或右侧列表选中；移动、复制、删除、8 色切换、三轴 90° 旋转、毫米坐标输入。
- 简化外框防重叠；十字轴穿入正确孔位会自动放行；其他机械装配可开启「允许重叠」。移动按 Esc 取消，拖动画布不会意外放置。
- 最多 60 步撤销 / 重做；新建、载入示例和打开作品也可撤销。本版本单件作品上限 500 个零件。
- 本浏览器自动保存；下载 `.brick.json` 保存可编辑作品，打开 JSON 继续搭建。导入会验证版本、ID、颜色、坐标、旋转和数量；无效文件不会覆盖当前作品。
- 整件作品导出 GLB；自带 21 件「彩虹门」示例及对应 JSON / GLB。

## 透明模型拼搭

点击工作台顶部的「选择模型拼搭」，通过成品缩略图选择 **林间小屋、庭院小树、城市小车、小小机器人、花园城堡**。模型使用同一套现有零件几何，直接进入原工作台的三维场景。

- 未完成位置显示为半透明目标；左侧零件盒只列出当前模型所需的规格、颜色及剩余数量。
- 选中零件后，匹配位置变成金色；点击目标，按模型的固定位置和方向自动对齐。错误规格、错误颜色与重复放置都会被拒绝。
- 默认按高度分层，未开放层保持淡淡的完整轮廓且不参与点击；关闭「分层拼搭」可按任意顺序填充。完成的实体积木正常遮挡后面的目标，旋转模型可换角度查看。
- 「帮我选下一块」选择当前层需要的零件；「填入一个高亮位置」提供等效按钮操作。填充只发生在明确点击后。
- 已填积木可选中、拆下、撤销和重做；模型模式固定零件姿态与颜色，自由移动/旋转/复制不在此模式开放。
- 自由作品与每个模型的进度分别保留在此浏览器；「返回自由拼搭」恢复原作品。「重新拼搭当前模型」可以撤销。
- `.brick.json` 保留模型身份与已填位置，刷新或重新导入能继续；导出 GLB 仅包含已填入的实体零件，不包含透明目标。
- 模型选择弹窗打开时，工作台快捷键暂停，避免在弹窗后误操作作品。

模型模板使用稳定的位置 ID 和版本；修改已发布模板的零件 ID / 位置时，需要同步处理模板版本及存档迁移。当前检查验证模型零件合法、外包围盒无冲突及至少一个逻辑凸点/轴孔连接，不等于实物承重、配合公差或生产验证。

本轮验证：`npm run check:guided` 覆盖五个模型逐层拼完、规格和颜色匹配、重复/跨层拒绝、零件余量、拆下与撤销重做、存档恢复，以及透明目标的拾取和生命周期。通过类型检查、构建和原装配/轮轴/快捷键检查。尚未进行本轮桌面浏览器实测和手机触摸验收。

## 快速开始

1. 点左侧零件，再点工作台空地或已有砖块的顶部放置。红色预览表示外框冲突。
2. 按 Esc 回到选择模式，点击已有零件，在右侧调整颜色和位置。选中后，在画布内单击右键，绕 Y 轴旋转 90°；放置 / 移动预览也支持。右键拖动仍平移视角，不会旋转零件。
3. 点「移动」或按 M 后重新选落点；「复制」会进入放置模式，原零件保留。
4. R 绕 Y 轴转 90°，F 查看全部，Delete 删除，⌘/Ctrl Z 撤销，⌘/Ctrl Shift Z 重做，⌘/Ctrl S 保存文件。
5. 保存文件用于备份或跨浏览器继续；GLB 用于其他三维软件查看，不作为本编辑器的可编辑存档。

桌面鼠标是已验收输入方式。手机布局已提供，但未进行手机或触摸设备验收。

## 车轮与十字轴连接

1. 先把带孔砖或机械梁放到合适高度，把十字轴移到其金色孔位，自动转向后点击插入。
2. 选择车轮，把鼠标移到轴端的金色连接点。出现「已对齐轴孔 · 插入 8.0 mm」后点击确认。无需打开「允许重叠」。
3. 可从车轮反向装入轴，也支持齿轮轴孔。现有车轮使用十字轴孔；连接销仍需手动放置。
4. 轴太低会导致轮胎穿过地面，预览会给出所需抬高距离；编辑轴或承载零件的 Y 坐标后重试。
5. 右下角「轮轴示例」提供已装配的带孔砖、4L 十字轴和两个 Ø24 车轮。示例的轮胎落在地面，载入操作可撤销。

自动轴孔吸附会调整位置与三轴方向，按孔深 / 轴端深度限制插入（最多 8 mm）。碰撞检查只放行真正同轴且穿入孔内的十字轴，旁边其他积木和重复车轮仍会被拦截。连接状态由位置和方向重新计算，保存、导入、撤销后不会丢失。

这是静态装配定位，不是关节系统；移动承载零件不会带动车轮，也没有传动或滚动物理。

## 自定义快捷键

点击工作台右下角「快捷键 · 设置」，或在非输入状态按 `?` 打开设置面板。19 项操作支持点击改键、冲突检查、自动记忆和恢复默认。`Esc` 与 `?` 固定保留；不拦截搜索、名称、坐标输入和中文输入法组词。长按不会连续执行删除、旋转或创建多条撤销记录。

| 操作 | 默认快捷键 |
| --- | --- |
| 移动零件 | M |
| 绕 Y / X / Z 轴旋转 90° | R / X / Z |
| 世界 X / Z 方向平移 8 mm | ← → / ↑ ↓ |
| 降低 / 升高 3.2 mm | Q / E |
| 复制 / 删除 | ⌘D / Delete 或退格 |
| 撤销 / 重做 | ⌘Z / ⌘Shift Z |
| 保存文件 / 查看全部 | ⌘S / F |
| 网格显示 / 吸附开关 | G / H |
| 搜索零件 | / |

Windows 的 ⌘ 对应 Ctrl。坐标微调仅作用于已放置且选中的零件，并沿用地面限制和防重叠检查；不会带动相接零件。改键只影响本浏览器，不写入作品 JSON。支持字母、数字、方向键、Delete、/ 及 Shift 组合；浏览器保留的常见组合会被拒绝。设置读取失败会回到默认，存储不可用会提示本次会话有效。

验证：`npm run check:shortcuts` 覆盖组合键归一化、冲突、保留按键、输入法、设置恢复；桌面实测改键、冲突提醒、刷新记忆、新按键旋转、输入框保护、方向键微调、升降与撤销。

## 拼搭数据约定

- 源模型和 JSON 单位：**毫米**。GLB 场景单位：**米**，通过根节点 0.001 比例换算。
- 坐标：Y 向上，X 沿长度，Z 沿宽度；底面中心为原点。
- 基础网格：凸点间距 8 mm；薄板高度 3.2 mm；标准砖高度 9.6 mm；凸点高 1.8 mm。
- 工作台中的基础砖、薄板、光面板和底板使用贴合网格的显示外壳，消除原来 0.2 mm 外形缩量与外圆角造成的透背景细缝；透明目标、实体、成品缩略图及整件 GLB 使用一致外形。凸点、接口、已有存档位置与机械零件不缩放。零件图鉴及单件导出仍保留原始外形。`npm run check:seams` 用小车红色车身和蓝色车厢的实际连接位置复现旧缝隙，并检查修正后射线命中外表面。
- 每个零件有稳定 `id`。`createPart(getPart(id), color)` 返回 `group`、共享可换色材质和 `dispose()`。
- 5950 个连接点总记录包含类型、位置、法线、半径、深度和截面类型。机械孔两端分别记录入口。
- 连接点类型：`stud`、`socket`、`pin-hole`、`pin-end`、`axle-hole`、`axle-end`。
- 凸点锚点位于凸点根部平面，底部接口位于零件底面。二者对齐时，高层零件的底面落在低层零件的顶面。
- GLB 中的连接点数据仍以毫米表示，见根节点 `connectorCoordinateUnits`；不可把元数据数值直接当作米。
- 这些连接点是**逻辑装配接口**，不是已验证的实体配合约束。当前支持普通凸点和十字轴孔吸附、有限插入深度与外框防重叠；尚未实现通用插入深度求解、孔轴自由度、精确网格碰撞、摩擦、公差、齿轮啮合或关节动力学。
- 齿轮使用简化齿形；模型由多个几何部件组成，未布尔融合，不适合作为生产或直接打印的工程图纸。
- 大量重复凸点采用实例化渲染；GLB 导出展开为标准共享几何的 mesh 节点，避免依赖 GPU 实例化扩展。

## 当前边界

- 普通凸点叠搭处理保持直立的零件；车轮 / 齿轮轴孔与十字轴、带孔砖 / 机械梁与十字轴另有自动对齐和插入。
- 防重叠是排除凸点后的零件外包围盒检测，L 形、圆形、空腔和机械件可能被保守拦截，可用「允许重叠」手动装配。
- 坐标编辑允许悬空摆放；没有重力、承重或支撑稳定性求解。移动一块积木不会带动与之相接的其他零件。
- 浏览器自动保存只保留当前作品，历史撤销不跨刷新。不同浏览器的自动存档不互通。
- 500 件是文档数量上限，不是性能承诺；大底板和高细节机械零件会增加开销。

## 源码入口

- `src/entry.ts`：工作台 / 图鉴入口，显式按模式初始化，独立 HTML 使用同一逻辑。
- `src/assembly.ts`：唯一作品状态、撤销历史、校验、网格 / 凸点吸附与简化碰撞。
- `src/editor.ts` / `src/editor.css`：拼搭界面、Three.js 场景、鼠标键盘交互和存档。
- `src/build-models.ts` / `src/build-guide.ts`：五个版本化模型模板、零件清单、填充规则和存档身份。
- `src/build-targets.ts`：透明目标的显示、层级拾取和资源释放；不进入实体导出。
- `src/project-export.ts`：作品 GLB 导出；毫米原始变换由唯一根节点转为米。

- `src/catalog.ts`：137 个规格、分类、搜索。
- `src/parts.ts`：所有零件的几何生成和导出转换。
- `src/connectors.ts`：连接点与逻辑类型兼容表。
- `src/library.ts`：零件库页面、单一预览场景、缩略图懒加载与导出。
- `src/library.css`：页面布局和交互状态。
- 原单块积木实现保留在 `src/brick.ts`、`src/main.ts`，早期独立交付包仍保留。
